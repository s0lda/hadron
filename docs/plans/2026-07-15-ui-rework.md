# UI Rework Plan

## 1. Completions Rework
- Render a custom `HoverCard` overlay directly in `app.rs`.
- Anchor it `bottom`-above the input and make it `w_full` to match input width.
- Drive it using the existing `completions.rs` logic to avoid `gpui-component` fork issues.

## 2. Tabs and Fields Polish
- Restyle using lattice palette tokens (rounded corners, subtle borders).
- Add active-tab accent underline.
- Add a faint radial glint (bg gradient) on the window root.

## 3. Glass on Dark Layers
- Apply a semi-transparent fill.
- Add a hairline top highlight on the chat area and right sidebar to simulate depth.

## 4. Autoscroll Bug
- On Shift+Enter text changes, defer the `scroll_to_bottom` call to `window.on_next_frame`.

## 5. Real PTY/VTE Terminal Emulator
- Replace the line-buffered command history with a real PTY-based interactive terminal session (e.g. using `portable-pty` or direct tokio-pty integration).
- Implement interactive character/line cell grid rendering in GPUI, parsing ANSI escape sequences and colors.
- Stream stdin inputs directly byte-by-byte to the PTY, enabling interactive CLI programs (like `vim`, `top`, interactive git paging).

## 6. Backstop Configuration & Mode Exemption
- Exclude turns running in Bypass Mode from triggering the backstop exchange count.
- Allow configuring the backstop limit (`max_exchanges`) via an optional `max_exchanges` field in `team.json` (defaults to 12).

## 7. Clear Command Implementation
- Implement a `/clear` slash command in the chamber.
- Archive the current `field.jsonl` to `.hadron/sessions/{session_id}/field.jsonl`.
- Create a new/empty `field.jsonl` in `.hadron` to clear the chat.
- Propagate the clear command to active quarks (including ACP quarks) to reset their state.
