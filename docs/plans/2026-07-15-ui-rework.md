# UI Rework Plan

## 1. Completions Rework
- Render a custom `HoverCard` overlay directly in `app.rs`.
- Anchor it `bottom`-above the input and make it `w_full` to match input width.
- Drive it using the existing `completions.rs` logic to avoid `gpui-component` fork issues.

## 2. Tabs and Fields Polish
- Restyle using lattice palette tokens (rounded corners, subtle borders).
- Add active-tab accent underline.
- Add a faint radial glint (bg gradient) on the window root.

## 3. Glass on Dark Layers
- Apply a semi-transparent fill.
- Add a hairline top highlight on the chat area and right sidebar to simulate depth.

## 4. Autoscroll Bug
- On Shift+Enter text changes, defer the `scroll_to_bottom` call to `window.on_next_frame`.
