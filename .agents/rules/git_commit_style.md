# Git Commit Message Convention

All git commit messages authored, amended, or reworded must follow this exact format:

`<type>(<scope>) - <short description>`

followed by a blank line and a bulleted list detailing the changes:

```text
<type>(<scope>) - <short description>

- <detailed change bullet 1>
- <detailed change bullet 2>
```

#### Example
```text
chore(ui) - update Tasks tab layout and Delegation styling

- Restyle Tasks tab cards to match Delegation view palette
- Update live elapsed clock and status badges
```
